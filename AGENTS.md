# Repository guidance

JevNexus provides bounded, advisory repository decisions through `repo_decide`. Treat Jev's answer as a recommendation; inspect relevant source and verify it before changing code. Use retrieval diagnostics only when troubleshooting evidence quality.

Keep diagnostics local by default. They can contain source code, questions, and decision results; review and sanitize them before sharing. Never include API keys or complete private evidence bundles in issues or commits.
